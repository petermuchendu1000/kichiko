# Elopis logo files

Generated by `apps/web/scripts/build-brand-assets.mjs`. Do not retouch by hand;
change the mark (`public/logo-tile.svg`) or the wordmark ratios in the script
and re-run it. Served at `https://elopis.com/brand/<file>`.

| file | size | use |
|---|---|---|
| `elopis-logo-full.png` | 1424×512, transparent | the lockup, on light backgrounds |
| `elopis-logo-full-on-dark.png` | 1424×512, transparent | the lockup, on dark backgrounds |
| `elopis-logo-full.jpg` | 1424×512, white | wherever JPG is forced |
| `elopis-mark.png` | 1024×1024, transparent | square mark alone: avatars, app icons, OAuth consent screens |
| `elopis-mark.jpg` | 1024×1024, white | square mark, JPG |

**Construction.** Blue `#1452F0` tile, `E` inside empty brackets: the
expectation operator, `E[X]`, since a market price is the expected value of a
binary payoff. Wordmark is Inter 700 at `-0.025em`, the same treatment the
navbar, footer, auth shell and auth dialog all use; it sits at 15/28 of the
mark's height with a gap of 8/28, and its cap box is centred on the mark.

**Clearspace.** Files are trimmed to the ink. Keep free space of at least half
the mark's height on every side.

**Colour.** Never recolour the tile. On a blue or busy background, place the
white-wordmark file over a solid panel rather than knocking the tile out.
